# Modèles d'e-mails d'authentification

Ces modèles se collent à la main dans Supabase, rubrique Authentication > Emails > Templates.
Supabase ne les lit pas depuis ce dépôt : toute retouche ici doit y être recopiée.

| Modèle Supabase | Fichier | Objet |
|---|---|---|
| Confirm signup | `confirmation.html` | Khârn-Âges Builder - Confirmation d'inscription |
| Reset password | `recovery.html` | Khârn-Âges Builder - Demande de réinitialisation de mot de passe |

Le logo est servi par le site déployé (`public/email/ka-logo.png`) : il ne s'affiche dans les
mails qu'une fois ce fichier en ligne.
